# 疯狂水世界 / Crazy Water World

浏览器里玩的水上乐园滑道街机游戏：坐充气泳圈冲下一条永远滑不完的滑道，
捡金币、钻水环、躲开橡皮鸭——小心弯道的离心力会把你甩出水槽。

纯 TypeScript + Canvas 2D + Web Audio，零后端、零外部资源，构建产物为可离线的静态站点。

## 本地运行

```bash
npm install
npm test        # node --test 单测（34 项）
npm run dev     # 开发服务器，默认 http://127.0.0.1:5173
```

其他脚本：

```bash
npm run build    # tsc --noEmit + vite build → dist/
npm run preview  # 预览 dist/ 构建
npm run bench    # Node 微基准：世界生成 / 速度模型 / 粒子
npm run probe    # 确定性探针：同一输入磁带跑两遍逐位比对 + 万米长局世界覆盖
npm run smoke    # 文件与内容冒烟检查
```

## 操作

| 输入 | 动作 |
| --- | --- |
| `A` / `←`、`D` / `→` | 左 / 右换道 |
| `空格` / `W` / `↑` | 小跳，可越过橡皮鸭（撞上充气障碍就没这么走运） |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 菜单主操作（开始 / 继续 / 再来一局） |
| `M` | 静音切换（标题 / 暂停 / 结算面板打开时；也可点面板右上角按钮） |
| 触屏 | 左 / 右侧点按换道，中间点按跳跃，水平滑动连续换道 |

## 玩法

- **流式无限滑道**：世界随滑行实时续生，跑多远都有内容。
  种子 = `日期天数 ^ runId`，同一天同一 runId 的世界完全可复现。
- **四主题循环**：热带港 → 洞穴瀑 → 火山泉 → 霓虹夜，按距离依次出现并平滑混色，
  跑完一轮再从热带港来过，无限循环、无硬切。
- **两种死法**：泳圈气量（HP）3 点，撞瘪归零进结算；或者在弯道被甩上滑道壁、
  离开水流太久，整个人被甩出滑道（落水结算）。贴墙硬转向会持续刮墙掉速。
- **计分**：金币 +10、宝石 +50、水环 +100（附短暂无敌）；连击越高加成越多，
  1.8 秒不吃东西断连；连续无伤收集 15 个回 1 点气量；加速带 1.6× 速度。
- **音频**：SFX 与 BGM（pad + 琶音）全部 Web Audio 现场合成，首次点击解锁，
  静音一键切换。

最高分存在浏览器 `localStorage`（键 `cww_hiscore_v1`）。
