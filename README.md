# 疯狂水世界 — 海上末日生存

陆地没了，木筏还在。这是一个**浏览器海上拾荒生存原型**：
开小船捞垃圾、把 3×3 木筏铺成浮岛、养活岛民，扛过风暴和海盗。
不使用任何官方角色、立绘或代言人肖像。

## 怎么玩

你从一块 3×3 木筏起家，正中是**指挥中心**——它被拆掉，或者岛民断水
断粮超过宽限时间（25 秒），这一局就结束了。目标：活得越久越好。

1. **捞**：WASD（或方向键）开拾荒小船出海，靠近漂浮物按**空格**捞起
   木板、塑料、金属、绳索（按住可以连捞）。漂浮物会漂走、会沉，
   看到就去抢。
2. **建**：数字键 1–5 选建筑（再按一次取消），点格子放置；右键或
   Esc 取消选中。**地基**只能铺在紧贴木筏的海面上（上下左右，不算
   斜角）；其他建筑必须盖在空地基上。
3. **养**：淡水和食物一直在消耗，而且**每盖一座建筑就多来一个岛民**
   ——多一双手也多一张嘴。尽早各建一座**净水机**和**钓鱼台**保住
   收支平衡；岛民还会自动花木板修补受损的格子。
4. **守**：开局约 50 秒起，风暴周期性抽打浮岛**外圈**（落雷前 4 秒
   会把目标格标红）——多铺几层地基当防波堤，别让产出建筑裸奔在最
   外侧。海盗紧随其后登场，直奔木筏贴身拆家，**炮塔**是唯一反制
   手段；击沉海盗还会掉金属。

### 操作一览

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格（可按住） | 捞取身边的漂浮物 |
| 1–5 | 选建筑（再按一次取消） |
| 点击格子 | 放置选中的建筑 |
| 右键 / Esc | 取消选中 |
| P / Esc | 暂停 / 继续 |

触屏：按住拖动当虚拟摇杆开船，轻点等于点击。

### 建筑一览

| 键 | 建筑 | 作用 | 花费 |
| --- | --- | --- | --- |
| 1 | 地基 | 扩张浮岛，防波挡刀 | 木板 4 + 绳索 2 |
| 2 | 收集器 | 每 5 秒产木板、塑料各 1 | 木板 6 + 塑料 4 |
| 3 | 净水机 | 每 3 秒产淡水 3 | 塑料 6 + 金属 4 |
| 4 | 钓鱼台 | 每 3 秒产食物 2 | 木板 5 + 绳索 4 |
| 5 | 炮塔 | 自动射击射程内海盗 | 金属 8 + 木板 4 |

### 老大的生存备忘

- 什么都不建的话，淡水撑约两分钟就见底——先把净水机、钓鱼台立起来。
- 开局金属 8 恰好一座炮塔，但净水机也要金属 4，二选一：缺口靠出海
  捞金属，或者靠炮塔击沉海盗掉的金属（每艘 2）回血。
- 首场风暴约 50 秒、海盗首波约 55 秒，而且间隔会越打越密——
  别指望背板，留冗余。
- 仓库有上限（建材 99、水/食 100），堆满了再捞是白捞；缺什么捞什么。
- 暂停时世界完全冻结（切后台也一样），不会回来发现岛没了。

## 本地运行

```bash
npm install
npm run dev      # 开发服（Vite）
npm test         # 规则单测
npm run build    # 类型检查 + 产物构建
npm run smoke    # 文件完整性冒烟
```
