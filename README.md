# 疯狂水世界 — 海上末日生存

陆地没了，木筏还在。这是一个**浏览器海上拾荒生存原型**：
开小船捞垃圾、把 3×3 木筏铺成浮岛、养活岛民，扛过风暴和海盗。
不使用任何官方角色、立绘或代言人肖像。
当前是纯浏览器原型，无后端、无账号：一切逻辑跑在本地，
最好成绩只存于浏览器 localStorage。

## 入口在哪（多游戏目录）

这是一个**多游戏仓库**：仓库根的 `index.html` 只是入口导航页，
海上生存游戏整包住在 `games/sea/`。

| 想去哪 | 地址 |
| --- | --- |
| 入口导航页（开发服） | `npm run dev` 后开 http://127.0.0.1:5173/ |
| **直接玩海上生存**（开发服） | http://127.0.0.1:5173/games/sea/ |
| 入口导航页（构建产物） | `npm run build && npm run preview` 后开 http://127.0.0.1:4173/ |
| 直接玩海上生存（构建产物） | http://127.0.0.1:4173/games/sea/ |

静态托管同理：部署 `dist/` 后，站点根是入口页，`/games/sea/` 是游戏。
以后加新游戏就再开一个 `games/<id>/` 子目录，根目录不放游戏源码。

## 怎么玩

你从一块 3×3 木筏起家，正中是**指挥中心**——它被拆掉，或者岛民断水
断粮超过宽限时间（25 秒），这一局就结束了。目标：活得越久越好。

1. **捞**：WASD（或方向键）开拾荒小船出海，靠近漂浮物按**空格**捞起
   木板、塑料、金属、绳索（按住可以连捞）。漂浮物会漂走、会沉，
   看到就去抢。
2. **建**：数字键 1–5 选建筑（再按一次取消），点格子放置；右键或
   Esc 取消选中。**地基**只能铺在紧贴木筏的海面上（上下左右，不算
   斜角）；其他建筑必须盖在空地基上。
3. **养**：淡水和食物一直在消耗，而且**每盖一座建筑就多来一个岛民**
   ——多一双手也多一张嘴。尽早各建一座**净水机**和**钓鱼台**保住
   收支平衡；岛民还会自动花木板修补受损的格子。
4. **守**：开局约 50 秒起，风暴周期性抽打浮岛**外圈**（落雷前 4 秒
   会把目标格标红）——多铺几层地基当防波堤，别让产出建筑裸奔在最
   外侧。海盗紧随其后登场，直奔木筏贴身拆家，**炮塔**是唯一反制
   手段；击沉海盗还会掉金属。

### 操作一览

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格（可按住） | 捞取身边的漂浮物 |
| 1–5 | 选建筑（再按一次取消） |
| 点击格子 | 放置选中的建筑 |
| Q / E | 交付岛民请求板上当前条子 |
| 右键 / Esc | 取消选中 |
| P / Esc | 暂停 / 继续 |

触屏：按住拖动当虚拟摇杆开船，轻点等于点击。

### 建筑一览

| 键 | 建筑 | 作用 | 花费 |
| --- | --- | --- | --- |
| 1 | 地基 | 扩张浮岛，防波挡刀 | 木板 4 + 绳索 2 |
| 2 | 收集器 | 每 5 秒产木板、塑料各 1 | 木板 6 + 塑料 4 |
| 3 | 净水机 | 每 3 秒产淡水 3 | 塑料 6 + 金属 4 |
| 4 | 钓鱼台 | 每 3 秒产食物 2 | 木板 5 + 绳索 4 |
| 5 | 炮塔 | 自动射击射程内海盗 | 金属 8 + 木板 4 |

### 老大的生存备忘

- 什么都不建的话，淡水撑约两分钟就见底——先把净水机、钓鱼台立起来。
- 开局金属 8 恰好一座炮塔，但净水机也要金属 4，二选一：缺口靠出海
  捞金属，或者靠炮塔击沉海盗掉的金属（每艘 2）回血。
- 首场风暴约 50 秒、海盗首波约 55 秒，而且间隔会越打越密——
  别指望背板，留冗余。
- 仓库有上限（建材 99、水/食 100），堆满了再捞是白捞；缺什么捞什么。
- 暂停时世界完全冻结（切后台也一样），不会回来发现岛没了。

### 本轮正在接进游戏的新玩法（模块已就位）

规格见 `.agent_workspace/GAME_SPEC.md` §6–§8.5，模块已落地、正在接线：

- **随身道具袋**：14 种有名字、有描述的物品（油布、鱼干、净水囊、
  铜罗盘……），捞取附带掉落、有保底；咸海带/鱼干/净水囊能应急吃喝。
- **岛民请求板**：岛民贴条子收建材、兑水/食，连交有加成、过期不
  倒扣——富余材料的第二去处（Q/E 一键交付已可用）。
- **轻剧情**：手写日志与短波电台条目随天数和建造进度解锁，
  轻松不丧，每条一局只出现一次，日志本可回看。
- **海面直接看得见目录物**：一部分漂浮物穿着油布/空油桶/咸海带的
  外观漂过来——捞到手入库的还是四种建材，不另开经济。
- **里程碑**：首座净水机、撑过首场风暴、木筏 12 格、活到第 3 天，
  达成有庆祝、进结算。

## 仓库速览

- 玩法规格：`.agent_workspace/GAME_SPEC.md`
- 架构与模块契约（含多游戏目录与新系统接口）：`.agent_workspace/ARCHITECTURE.md`
- 游戏源码全部在 `games/sea/src/`：规则/产消/威胁在 `sim/`，
  小船/海盗在 `entities/`，绘制在 `world/` 与 `fx/`，HUD 与菜单在 `ui/`
- 平衡数值的唯一真源是 `games/sea/src/data/constants.ts`——sim 与
  entities 直接 import 它的表，改平衡改一处即可（详见该文件头注释）
