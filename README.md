# 疯狂水世界 / Crazy Water World

浏览器里玩的水上乐园滑道街机游戏：坐充气泳圈冲下滑道，捡金币、钻水环、躲开障碍。

## 本地运行

```bash
npm install
npm test
npm run dev
```

打开终端提示的本地地址（默认 `http://127.0.0.1:5173`）。

```bash
npm run build
npm run preview
npm run bench
npm run smoke
```

## 操作

- 键盘：`A` / `←` 左换道，`D` / `→` 右换道，`空格` 跳跃，`P` 暂停
- 触屏：点左右半屏换道，点中间跳跃
