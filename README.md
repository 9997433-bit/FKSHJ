# 疯狂水世界 — 海上末日生存

陆地没了，木筏还在。这是致敬益世界同名手游的**浏览器海上生存原型**：
开小船捞垃圾、把 3×3 木筏铺成浮岛、养活三个岛民，扛过风暴和海盗。
不是水上乐园滑道；不使用官方角色、立绘或代言人肖像。

## 怎么玩

你从一块 3×3 木筏起家，正中是**指挥中心**——它被拆掉，或者岛民断水
断粮超过宽限时间，这一局就结束了。目标：活得越久越好。

1. **捞**：WASD 开拾荒小船出海，靠近漂浮物按空格（或点按）捞起
   木板、塑料、金属、绳索。漂浮物会漂走、会沉，看到就去抢。
2. **建**：数字键 1–5 选建筑，再点格子放置。**地基**只能铺在紧贴
   木筏的海面上（上下左右，不算斜角）；其他建筑必须盖在空地板上。
3. **养**：淡水和食物一直在消耗。尽早各建一座**净水机**和**钓鱼台**
   就能收支平衡；**收集器**会慢慢攒建材，但大头还是靠出海捞。
4. **守**：风暴周期性抽打浮岛**外圈**——多铺几层地板当防波堤，别让
   产出建筑裸奔在最外侧。海盗晚一些登场，直奔外圈建筑贴身拆家，
   **炮塔**是唯一反制手段，攒够金属尽快立起来。

### 操作一览

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格 / 点按靠近的漂浮物 | 捞取 |
| 1–5 再点格子 | 选建筑并放置 |
| P / Esc | 暂停 / 继续 |

### 建筑一览

| 键 | 建筑 | 作用 | 主要花费 |
| --- | --- | --- | --- |
| 1 | 地基 | 扩张浮岛，防波挡刀 | 木板 + 塑料 |
| 2 | 收集器 | 被动产木板/塑料 | 木板 + 塑料 + 绳索 |
| 3 | 净水机 | 产淡水（一座养活全队） | 塑料 + 金属 |
| 4 | 钓鱼台 | 产食物（一座养活全队） | 木板 + 绳索 |
| 5 | 炮塔 | 自动射击射程内海盗 | 金属 + 塑料 + 绳索 |

### 老大的生存备忘

- 开局库存刚好够净水机 + 钓鱼台各一座，先把命续上再谈扩张。
- 首场风暴约在两分半，海盗首波约在四分钟——中间这段就是攒金属
  造炮塔的窗口，金属只能捞，别指望收集器。
- 仓库有上限，堆满了再捞是白捞；缺什么捞什么。
- 暂停时世界完全冻结（切后台也一样），不会回来发现岛没了。

```bash
npm run smoke    # 文件完整性冒烟
```
