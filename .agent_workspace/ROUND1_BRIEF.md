# Round 1 简报 — 扩玩法 + 多游戏目录

## 目录契约（已经落地，不要再搬一次）

- 海上生存整包在 `games/sea/`（`index.html` + `src/**`）
- 仓库根 `index.html` 是游戏入口页，链到 `./games/sea/`
- 以后新游戏加 `games/<id>/`，不要往根 `src/` 塞
- 运行时仍以 `games/sea/src/sim` 为准；`session.ts` / `main.ts` 父调度器接线
- 存档键继续 `cww_sea_v1`，不要改成会冲掉玩家纪录的新键，除非加字段且能兼容读

## 本轮要长出来的东西（SOTA，不是再做一套滑道）

模仿益世界《疯狂水世界》同品类：**海上拾荒 + 浮岛基建 + 养活岛民**。
禁止官方角色名/立绘、陈小春肖像、官方曲、照抄数值表。

1. **物品**：可辨认的打捞物/道具目录（不只是四种建材堆数字），要有名称、短描述、用途
2. **剧情**：轻量日记/广播/岛民闲话，随天数或建筑解锁，轻松不丧
3. **玩法**：至少一种新循环（例如配方加工、任务板、探索点、岛民请求）——必须接到 sim，不能只是文案
4. **目录隔离**：确认测试/探针/构建都走 `games/sea`，根目录保持可加第二款游戏

## 不要动

- 别人的 OWNERSHIP 路径
- 官方 IP
- 把游戏再搬回根 `src/`

首行必须：`MODEL_SLUG: <实际 slug>`
