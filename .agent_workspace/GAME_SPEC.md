# 疯狂水世界 — 海上末日生存（规格）

模仿对象是益世界手游《疯狂水世界》（海上生存基建品类），
不是水上乐园滑道。本仓库做**同品类浏览器原型**：海上拾荒 + 浮岛基建 +
养活岛民。Round 1 长出三块并已接线：可辨认物品（§6）、轻剧情（§7）、
岛民请求板新循环（§8）。本轮（Round 2）把新层折进同一套海：海面
直接看得见目录物（§6.5）、捞取掉落进袋与应急吃喝（§6）、里程碑并进
请求板层（§8.5）——**不开新经济、不开新场景、不扩 snapshot**。
接口契约见 ARCHITECTURE §7（含 §7.5/§7.7 的 Round 2 支线），
按 §9 验收。

禁止：官方角色名/立绘、陈小春肖像、官方曲、照抄数值表。
允许：洪水末日、木筏扩建、捞垃圾、净水钓鱼、风暴海盗、轻松摸鱼口气。

## 1. 技术栈

TypeScript + Vite + Canvas 2D + Web Audio。零后端，禁止 React/Three/大物理库。
多游戏目录：本作整包住 `games/sea/`，仓库根 `index.html` 只是入口导航页
（目录契约见 ARCHITECTURE §0）。

## 2. 核心循环

1. 开局 3×3 木筏，正中指挥中心。
2. WASD 开小船，空格/点击捞木板、塑料、金属、绳索。海面上有一部分
   漂浮物**穿着目录物的外观**漂过来（油布/空油桶/咸海带……，§6.5）
   ——捞到手入库的仍是四种建材；捞取另有概率连带捞出**袋装物品**
   （§6），连着不出会保底。
3. 1–5 选建筑，点海面铺地基或在空地板上盖房子。
4. 淡水/食物持续消耗；收集器/净水机/钓鱼台自动产；袋里的咸海带/
   鱼干/净水囊可以应急吃喝。
5. 岛民往**请求板**贴条子（§8）：交建材换水/食，连交有加成——
   富余材料的第二去处，也是缺水缺粮时的短期决策。
6. 风暴打外圈；海盗靠近时炮塔开火。指挥中心被拆或长时间断粮 = 结算
   （死因只有这两种）。
7. 日志与电台条目随天数/建造进度解锁（§7）；**里程碑**（首座
   净水机、撑过首场风暴、木筏 12 格、活到第 3 天）达成有庆祝、
   进结算（§8.5）。轻松不丧。

## 3. 操作

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格 / 点按靠近漂浮物 | 捞取 |
| 1–5 然后点格子 | 选建筑并放置 |
| Q / E | 交请求板上第一张交得起的条子 |
| P / Esc | 暂停 |

物品吃喝与按条子逐一选交走 HUD 点击区（键位与布局归 fable-sota 定），
硬约束只有一条：**局内完成、非模态**——不弹暂停窗口打断生存节奏。

## 6. 物品（新）

物品表在 `games/sea/src/data/catalog.ts`，道具袋在
`games/sea/src/sim/inventory.ts`（接口见 ARCHITECTURE §7.1–7.2）：

- **14 种可辨认物品**，每件有原创中文名与一句话描述：油布、空油桶、
  咸海带、鱼干、净水囊、鱼钩、活扳手、信号弹、铜罗盘、急救包，
  外加与四种建材同名的散料。标签分栏（打捞物/建材/口粮/饮水/工具/
  药品/容器/旧物），HUD 能看到名称与数量——不是「四种建材换皮堆
  数字」。名称全原创，禁官方 IP。
- 道具袋 16 格；单格堆叠上限因物而异（散料 99、杂物 5–30、独件 1），
  一种东西可占多格。装取**原子**，溢出丢弃语义要显式声明
  （`{ partial: true }`）。
- 物品与六种资源是**两本账**：袋里的木板不是仓库的木板，不相加。
- 获取（接线，数在 constants.ITEM_DROP）：捞取成功按 `chance`（25%）
  附带掉一件；连续 `pityScoops`（5）次不掉则下一次**必掉**（保底）。
- 用途（接线，汇率在 constants.ITEM_USE）：咸海带（+4 食）、鱼干
  （+8 食）、净水囊（+8 水）可直接吃喝应急，入库受资源上限截断；
  其余物品先当收藏/展示，工具与配方是后续轮议题。

## 6.5 海面刷目录物（Round 2 新开）

海面上要**看得见**目录里的东西，但**不另开第二套掉落经济**
（契约见 ARCHITECTURE §7.7.1）：

- 新刷漂浮物按 `JUNK_LOOKS.chance`（35%）穿一件目录物外观，
  走 `Junk.look` 现成字段；look → 建材的映射固定（如油布→塑料、
  空油桶→金属、咸海带→木板）。
- 入库规则一分不变：`Junk.kind` 仍限四种建材，捞取产出仍按
  `SALVAGE.yields` 掷、走 `gain()` 入资源——玩家看见的是
  「一只空油桶」，捞到手的是金属。
- 飘字/水花/图鉴按 look 表现（「捞到 空油桶」而不是「捞到 金属」），
  管道 Round 1 已就位（`JunkHaul.look`）；掉落掷骰（§6 的保底线）
  可拿 look 做偏向——穿油布外观的更容易掉油布。
- 换装随机走海面自己的 LCG，同种子同海面；不碰 session.rng。

## 7. 剧情（新）

条目表在 `games/sea/src/story/beats.ts`，解锁调度在 `story/index.ts`
（接口见 ARCHITECTURE §7.4）：

- 两种口吻：**日志**（老大手写）与**电台**（短波里别人的声音），
  一条 1–2 句，轻松不丧，文案全原创。
- **10 条起步**；解锁条件是天数 / 存活秒数 / 建筑数量的**与**组合：
  开局第一条即上屏，盖出收集器/净水机/钓鱼台/炮塔各解一条，
  第 2/5/7 天各有里程碑条目。
- 一帧最多上屏一条，同帧满足多条按表序排队；日志停留 8s、电台 10s
  后自动收走。每条一局只解锁一次，日志本可回看（unlockedBeats），
  进度可显示「已解锁 n / 10」。
- 展示非模态（HUD），不暂停、不弹窗；暂停期间不推进。请求板的
  日记（§8）是第二路剧情素材，与这里互补。

## 8. 请求板（新循环）

岛民往板上贴条子，拿富余建材换生活物资
（`games/sea/src/sim/expand.ts`，接口见 ARCHITECTURE §7.3）：

- 节奏：开局 **12s** 贴第一张——早于首场风暴（50s），玩家先有个
  主动目标；之后每 26s 一张、逐张加密到 13s；板上最多 **3 张**，
  满了压住计时等空位；每张时限 75s 起、随难度档缩到 42s。
- 内容：8 个模板（补渔网/修屋顶/接雨槽/打汤锅/编吊床/做浮标/
  钉鱼箱/缝帆），要 1–2 种建材、兑水/食（偶尔搭材料）；
  **只贴当场交得起的单**，板上不出死单。
- 难度档：每 150s 升一档（最多 3 档），需求 +1/种、奖励
  ×(1 + 0.35×档)、时限 −11s。
- 交单**原子**：材料全够才扣（pay），奖励立即入库（超上限截断）；
  连交 3 张不断档奖励 ×1.5；过期只丢奖励、清连击，**从不倒扣**。
- 顺手产日记（who/text/tone，留 12 条）；完成数/连击进结算。
- 已真接进 sim 层（纯函数、走 Rng 可复现），session 已接线；
  单测可直接读 `BoardState` 与库存验证，不经 UI（注意
  `Session.snapshot()` 已冻结，板面状态不进 snapshot）。

## 8.5 里程碑（Round 2 新开，并进请求板层）

四条里程碑并进 `expand.ts` 旁路（判定阈值在 `constants.MILESTONES`，
契约见 ARCHITECTURE §7.7.2），**要有可测状态，不是只写文案**：

| id | 条件 | 读的状态 |
| --- | --- | --- |
| `first-purifier` | 首座净水机立起来 | purifier 计数 ≥ 1 |
| `first-storm` | 撑过首场风暴 | 已结算风暴场数 ≥ 1（局未结束） |
| `raft-12` | 木筏铺到 12 格 | raft.cells.size ≥ 12 |
| `day-3` | 活到第 3 天 | dayNumber ≥ 3（elapsed ≥ 240s） |

- 每条**一生一次**，达成顺序记在 `MilestoneState.done`——单测可
  直接断言（headless 铺到 12 格后 done 含 `raft-12`）。
- 判定纯阈值、**零 rng**；探针窗口内（第 1 天、至多 11 格、零
  净水机、零风暴）一条不触发，snapshot 不加字段，基线稳。
- 达成庆祝走 HUD 现有管道（quest 胶囊 / questDone 庆祝 / 请求板
  日记），不传新字段则画面与现状一致；达成数可进结算增量字段。

## 9. 验收

- 标题能开始，能捞、能建、能停、能死、能再来一局
- 海面看得见目录物外观（同一片海能遇到至少 3 种换装漂浮物）；
  捞取入库仍是四种建材、产出区间不变——look 不产生第二套经济
- 捞取能出袋装物品（有名称/描述、HUD 可见数量）；连捞 20 次至少
  见到 3 件（保底兜住）；掉落不改任何资源数字；咸海带/鱼干/净水囊
  用掉后资源立刻变化
- 开局 20 秒内请求板贴出第一张条子；能交一单（材料扣减、奖励入账、
  done +1）；不管的条子会过期并清连击
- 里程碑：headless 造出净水机 / 铺到 12 格 / 跑到第 3 天，
  `MilestoneState.done` 逐条可断言；同条不重复达成
- 开局即有第一条剧情上屏；盖出净水机/钓鱼台各解锁一条；同一条
  一局只出现一次；暂停期间剧情与请求板计时都不推进
- 单测覆盖：花费/邻接/断粮 + 道具袋原子装取 + 交单原子性 + 剧情
  单次解锁 + 板同种子复现 + 里程碑单次达成；**旧 13 测必须仍绿**
- 探针基线 `728b59b5` 不变：开局 5s（300 tick）零贴单、零
  session.rng 抽取，`Session.snapshot()` 不扩字段
- `npm test && npm run build && npm run smoke`（build 含 `tsc --noEmit`）
