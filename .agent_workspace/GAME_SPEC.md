# 疯狂水世界 — 海上末日生存（纠正后规格）

模仿对象是益世界手游《疯狂水世界》（陈小春代言：海上掌舵人），
不是水上乐园滑道。本仓库做**同品类浏览器原型**：海上拾荒 + 浮岛基建 + 养活岛民。

禁止：官方角色名/立绘、陈小春肖像、官方曲、照抄数值表。
允许：洪水末日、木筏扩建、捞垃圾、净水钓鱼、风暴海盗、轻松摸鱼口气。

## 1. 技术栈

TypeScript + Vite + Canvas 2D + Web Audio。零后端，禁止 React/Three/大物理库。

## 2. 核心循环

1. 开局 3×3 木筏，正中指挥中心。
2. WASD 开小船，空格/点击捞木板、塑料、金属、绳索。
3. 1–5 选建筑，点海面铺地基或在空地板上盖房子。
4. 淡水/食物持续消耗；收集器/净水机/钓鱼台自动产。
5. 风暴打外圈；海盗靠近时炮塔开火。指挥中心被拆或长时间断粮 = 结算。

## 3. 操作

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格 / 点按靠近漂浮物 | 捞取 |
| 1–5 然后点格子 | 选建筑并放置 |
| P / Esc | 暂停 |

## 4. 建筑

| id | 名称 | 作用 |
| --- | --- | --- |
| floor | 地基 | 必须四向贴着已有木筏 |
| collector | 收集器 | 产木板/塑料 |
| purifier | 净水机 | 产淡水 |
| fish | 钓鱼台 | 产食物 |
| turret | 炮塔 | 打海盗 |

## 5. 场景

`boot → title → playing ⇄ paused → gameover → title`

## 6. 验收

- 标题能开始，能捞、能建、能停、能死、能再来一局
- 单测覆盖花费/邻接/断粮
- `npm test && npm run build && npm run smoke`
