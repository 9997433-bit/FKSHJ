# 疯狂水世界 — 海上末日生存（规格）

模仿对象是益世界手游《疯狂水世界》（海上生存基建品类），
不是水上乐园滑道。本仓库做**同品类浏览器原型**：海上拾荒 + 浮岛基建 +
养活岛民。本轮（扩玩法 Round 1）长出三块新东西：可辨认物品（§6）、
轻剧情（§7）、岛民请求板新循环（§8）；模块已落地，接口契约见
ARCHITECTURE §7，接进 session 后按 §9 验收。

禁止：官方角色名/立绘、陈小春肖像、官方曲、照抄数值表。
允许：洪水末日、木筏扩建、捞垃圾、净水钓鱼、风暴海盗、轻松摸鱼口气。

## 1. 技术栈

TypeScript + Vite + Canvas 2D + Web Audio。零后端，禁止 React/Three/大物理库。
多游戏目录：本作整包住 `games/sea/`，仓库根 `index.html` 只是入口导航页
（目录契约见 ARCHITECTURE §0）。

## 2. 核心循环

1. 开局 3×3 木筏，正中指挥中心。
2. WASD 开小船，空格/点击捞木板、塑料、金属、绳索；捞取有概率连带
   捞出**袋装物品**（§6），连着不出会保底。
3. 1–5 选建筑，点海面铺地基或在空地板上盖房子。
4. 淡水/食物持续消耗；收集器/净水机/钓鱼台自动产；袋里的咸海带/
   鱼干/净水囊可以应急吃喝。
5. 岛民往**请求板**贴条子（§8）：交建材换水/食，连交有加成——
   富余材料的第二去处，也是缺水缺粮时的短期决策。
6. 风暴打外圈；海盗靠近时炮塔开火。指挥中心被拆或长时间断粮 = 结算
   （死因只有这两种）。
7. 日志与电台条目随天数/建造里程碑解锁（§7），轻松不丧。

## 3. 操作

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格 / 点按靠近漂浮物 | 捞取 |
| 1–5 然后点格子 | 选建筑并放置 |
| P / Esc | 暂停 |

物品吃喝与请求板交单走 HUD 点击区（键位与布局归 fable-sota 定），
硬约束只有一条：**局内完成、非模态**——不弹暂停窗口打断生存节奏。

## 4. 建筑

| id | 名称 | 作用 |
| --- | --- | --- |
| floor | 地基 | 必须四向贴着已有木筏 |
| collector | 收集器 | 产木板/塑料 |
| purifier | 净水机 | 产淡水 |
| fish | 钓鱼台 | 产食物 |
| turret | 炮塔 | 打海盗 |

## 5. 场景

`boot → title → playing ⇄ paused → gameover → title`

新系统不新增场景：物品、请求板、剧情全部发生在 playing 内。

## 6. 物品（新）

物品表在 `games/sea/src/data/catalog.ts`，道具袋在
`games/sea/src/sim/inventory.ts`（接口见 ARCHITECTURE §7.1–7.2）：

- **14 种可辨认物品**，每件有原创中文名与一句话描述：油布、空油桶、
  咸海带、鱼干、净水囊、鱼钩、活扳手、信号弹、铜罗盘、急救包，
  外加与四种建材同名的散料。标签分栏（打捞物/建材/口粮/饮水/工具/
  药品/容器/旧物），HUD 能看到名称与数量——不是「四种建材换皮堆
  数字」。名称全原创，禁官方 IP。
- 道具袋 16 格；单格堆叠上限因物而异（散料 99、杂物 5–30、独件 1），
  一种东西可占多格。装取**原子**，溢出丢弃语义要显式声明
  （`{ partial: true }`）。
- 物品与六种资源是**两本账**：袋里的木板不是仓库的木板，不相加。
- 获取（接线，数在 constants.ITEM_DROP）：捞取成功按 `chance`（25%）
  附带掉一件；连续 `pityScoops`（5）次不掉则下一次**必掉**（保底）。
- 用途（接线，汇率在 constants.ITEM_USE）：咸海带（+4 食）、鱼干
  （+8 食）、净水囊（+8 水）可直接吃喝应急，入库受资源上限截断；
  其余物品先当收藏/展示，工具与配方是后续轮议题。

## 7. 剧情（新）

条目表在 `games/sea/src/story/beats.ts`，解锁调度在 `story/index.ts`
（接口见 ARCHITECTURE §7.4）：

- 两种口吻：**日志**（老大手写）与**电台**（短波里别人的声音），
  一条 1–2 句，轻松不丧，文案全原创。
- **10 条起步**；解锁条件是天数 / 存活秒数 / 建筑数量的**与**组合：
  开局第一条即上屏，盖出收集器/净水机/钓鱼台/炮塔各解一条，
  第 2/5/7 天各有里程碑条目。
- 一帧最多上屏一条，同帧满足多条按表序排队；日志停留 8s、电台 10s
  后自动收走。每条一局只解锁一次，日志本可回看（unlockedBeats），
  进度可显示「已解锁 n / 10」。
- 展示非模态（HUD），不暂停、不弹窗；暂停期间不推进。请求板的
  日记（§8）是第二路剧情素材，与这里互补。

## 8. 请求板（新循环）

岛民往板上贴条子，拿富余建材换生活物资
（`games/sea/src/sim/expand.ts`，接口见 ARCHITECTURE §7.3）：

- 节奏：开局 **12s** 贴第一张——早于首场风暴（50s），玩家先有个
  主动目标；之后每 26s 一张、逐张加密到 13s；板上最多 **3 张**，
  满了压住计时等空位；每张时限 75s 起、随难度档缩到 42s。
- 内容：8 个模板（补渔网/修屋顶/接雨槽/打汤锅/编吊床/做浮标/
  钉鱼箱/缝帆），要 1–2 种建材、兑水/食（偶尔搭材料）；
  **只贴当场交得起的单**，板上不出死单。
- 难度档：每 150s 升一档（最多 3 档），需求 +1/种、奖励
  ×(1 + 0.35×档)、时限 −11s。
- 交单**原子**：材料全够才扣（pay），奖励立即入库（超上限截断）；
  连交 3 张不断档奖励 ×1.5；过期只丢奖励、清连击，**从不倒扣**。
- 顺手产日记（who/text/tone，留 12 条）；完成数/连击进结算。
- 已真接进 sim 层（纯函数、走 Rng 可复现），session 已接线；
  单测可直接读 `BoardState` 与库存验证，不经 UI（注意
  `Session.snapshot()` 已冻结，板面状态不进 snapshot）。

## 9. 验收

- 标题能开始，能捞、能建、能停、能死、能再来一局
- 捞取能出袋装物品（有名称/描述、HUD 可见数量）；连捞 20 次至少
  见到 3 件（保底兜住）；咸海带/鱼干/净水囊用掉后资源立刻变化
- 开局 20 秒内请求板贴出第一张条子；能交一单（材料扣减、奖励入账、
  done +1）；不管的条子会过期并清连击
- 开局即有第一条剧情上屏；盖出净水机/钓鱼台各解锁一条；同一条
  一局只出现一次；暂停期间剧情与请求板计时都不推进
- 单测覆盖：花费/邻接/断粮 + 道具袋原子装取 + 交单原子性 + 剧情
  单次解锁
- `npm test && npm run build && npm run smoke`（build 含 `tsc --noEmit`）
