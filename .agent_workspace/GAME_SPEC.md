# 疯狂水世界 — 海上末日生存（规格）

模仿对象是益世界手游《疯狂水世界》（海上生存基建品类），
不是水上乐园滑道。本仓库做**同品类浏览器原型**：海上拾荒 + 浮岛基建 +
养活岛民。本轮（扩玩法 Round 1）长出三块新东西：可辨认物品（§6）、
轻剧情（§7）、岛民委托板新循环（§8）；接口契约见 ARCHITECTURE §7。

禁止：官方角色名/立绘、陈小春肖像、官方曲、照抄数值表。
允许：洪水末日、木筏扩建、捞垃圾、净水钓鱼、风暴海盗、轻松摸鱼口气。

## 1. 技术栈

TypeScript + Vite + Canvas 2D + Web Audio。零后端，禁止 React/Three/大物理库。
多游戏目录：本作整包住 `games/sea/`，仓库根 `index.html` 只是入口导航页
（目录契约见 ARCHITECTURE §0）。

## 2. 核心循环

1. 开局 3×3 木筏，正中指挥中心。
2. WASD 开小船，空格/点击捞木板、塑料、金属、绳索；捞取有概率连带
   捞出**可辨认物品**（§6），连着不出会保底。
3. 1–5 选建筑，点海面铺地基或在空地板上盖房子。
4. 淡水/食物持续消耗；收集器/净水机/钓鱼台自动产。
5. 岛民往**委托板**挂单（§8）：按单交付物品/材料，换净赚的报酬——
   这是物品的主要去处，也是开船绕路的主动目标。
6. 风暴打外圈；海盗靠近时炮塔开火。指挥中心被拆或长时间断粮 = 结算
   （死因只有这两种）。
7. 日记与岛民闲话随天数/里程碑解锁（§7），轻松不丧。

## 3. 操作

| 输入 | 动作 |
| --- | --- |
| WASD / 方向键 | 开拾荒小船 |
| 空格 / 点按靠近漂浮物 | 捞取 |
| 1–5 然后点格子 | 选建筑并放置 |
| P / Esc | 暂停 |

物品使用与委托交付走 HUD 点击区（键位与布局归 fable-sota 定），
硬约束只有一条：**局内完成、非模态**——不弹暂停窗口打断生存节奏。

## 4. 建筑

| id | 名称 | 作用 |
| --- | --- | --- |
| floor | 地基 | 必须四向贴着已有木筏 |
| collector | 收集器 | 产木板/塑料 |
| purifier | 净水机 | 产淡水 |
| fish | 钓鱼台 | 产食物 |
| turret | 炮塔 | 打海盗 |

## 5. 场景

`boot → title → playing ⇄ paused → gameover → title`

新系统不新增场景：物品、委托、剧情全部发生在 playing 内。

## 6. 物品（新）

目录在 `games/sea/src/data/catalog.ts`（接口见 ARCHITECTURE §7.1）：

- 每件物品有 id、**原创中文名**、一句话描述、类别三选一：
  `consumable`（用了立刻加资源）/ `material`（委托要收的材料）/
  `trinket`（稀罕玩意，委托高价收）。名称禁官方 IP。
- 至少 **8 种**，三类各有代表；不是「四种建材换皮堆数字」，
  HUD 上能看到名称与数量，玩家叫得出名字。
- 获取：捞取成功时按 `ITEM_DROP.chance`（25%）附带掉一件；
  连续 `pityScoops`（5）次不出则下一次**必出**（保底）。
  委托奖励也能给物品。
- 持有：单种上限 `INVENTORY.maxPerItem`（20），超出丢弃；
  物品与六种资源分开存放，互不占上限。
- 用途至少两条真路径：consumable 当场用掉换资源（走 sim 的 gain，
  受资源上限截断）；material/trinket 交委托（§8）。

## 7. 剧情（新）

台词表在 `games/sea/src/story/lines.ts`，触发逻辑在 `story/index.ts`
（接口见 ARCHITECTURE §7.4）：

- 形式：日记 / 电台广播 / 岛民闲话，一条 1–2 句，口气轻松不丧。
- 触发至少三类：天数达到 N、首次盖出某种建筑、事件线索
  （首场风暴、首个海盗、首件物品、委托完成/过期……）。
- 每条**一生一次**（seen 去重）；两条至少隔 `STORY.minGapS`（8s）；
  单条在 HUD 停留 `STORY.toastS`（6s）；日志保留 `STORY.logMax`
  （40）条，超出丢最旧。
- 展示非模态（HUD toast / 字幕），不暂停、不弹窗；暂停期间不推进。

## 8. 委托板（新循环）

岛民把需求挂上委托板（`games/sea/src/sim/expand.ts`，接口见
ARCHITECTURE §7.3）：

- 节奏：开局 `REQUESTS.firstS`（35s）出第一单——早于首场风暴（50s），
  让玩家先有个主动目标；之后约 `intervalS`（40s）一单；板上最多
  `maxOpen`（3）单，满了挂起、腾格立刻补；每单 `expireS`（90s）过期。
- 单子内容：要物品和/或建材，数量随天数缓涨且**当下可完成**；
  报酬是资源/物品组合，**净收益为正**——接单是赚的，动机成立。
- 交付**原子**：wants 全够才扣（资源走 pay、物品走 takeItems），
  扣完奖励立即入库（受上限截断）；付不起分文不动。
- 必须真接进 sim：发单/过期/完成都改 `ExpandState` 与库存，
  完成数进结算；探针不点 UI 也能观测到状态变化。

## 9. 验收

- 标题能开始，能捞、能建、能停、能死、能再来一局
- 捞取能出可辨认物品（有名称/描述、HUD 可见数量）；连捞 20 次
  至少见到 3 件（保底兜住）；消耗品用掉后资源立刻变化
- 开局 60 秒内委托板出现第一单；能完成一单（交付扣减、奖励入账、
  完成数 +1）；不管的单子会过期
- 第 1 天内至少触发一条剧情台词；同一条台词全局只出现一次；
  暂停期间剧情与委托计时都不推进
- 单测覆盖：花费/邻接/断粮 + 物品原子扣取 + 交付原子性 + 台词单次触发
- `npm test && npm run build && npm run smoke`（build 含 `tsc --noEmit`）
